# 📘 Derivative Calculator

A simple web-based calculator for computing derivatives of mathematical functions.  
Built with **HTML, CSS, and JavaScript**, using the **Nerdamer** library for symbolic mathematics.

---

## 📖 Description
The Derivative Calculator allows users to compute first-order and higher-order derivatives of mathematical functions.  
It provides a clean interface where users can input functions and instantly view results.

---

## 🚀 Features
- Calculate first-order derivatives (support for higher-order can be extended).
- Supports polynomial, trigonometric, exponential, and logarithmic functions.
- Responsive and user-friendly interface.
- Real-time output display.

---

## 🛠️ Technologies Used
- **HTML** – Structure of the webpage  
- **CSS** – Styling and layout  
- **JavaScript** – Core logic and interactivity  
- **Nerdamer.js** – Symbolic math library
